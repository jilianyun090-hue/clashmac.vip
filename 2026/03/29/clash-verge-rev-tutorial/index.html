Clash Verge Rev 是经典客户端 Clash Verge 的开源延续版本。它采用 Tauri 框架构建，前端界面更加轻量且流畅，核心则集成了强大的 Clash Meta (Mihomo) 内核。

在延续了原有版本号规则和使用逻辑的基础上，Rev 版本对界面进行了深度美化，并优化了内存占用。对于已经习惯 Clash 系列产品的用户来说，几乎可以做到零学习成本上手。

🚀 核心优势

  • 轻量化设计：基于 Tauri 框架，比原版 Electron 版本更省内存。
  • 内核强大：内置 Mihomo 内核，支持最新协议（如 VLESS, Reality, Hysteria2 等）。
  • 界面美观：现代化的 UI 设计，支持多种主题切换。
  • 零成本迁移：完全兼容原 Clash Verge 的配置文件。

  • macOS 用户: 下载 .dmg 版本。

⚙️ Clash 订阅链接如何导入？快速上手配置指南

1. 导入订阅链接

  1. 打开 Clash Verge Rev，点击左侧菜单栏的 “配置 (Profiles)”。
  2. 在顶部的输入框中粘贴您的 机场订阅链接。
  3. 点击右侧的 “导入 (Import)” 按钮。
  4. 导入成功后，点击该配置文件使其生效（边框变色即代表激活）。

2. 选择节点

点击左侧菜单栏的 “代理 (Proxies)”，在上方选择 “规则 (Rule)” 模式（推荐），选择一个延迟较低的节点。

3. 开启代理

点击左侧菜单底部的 “设置 (Settings)”，找到 “系统代理 (System Proxy)” 选项，打开开关。

💡 Clash 进阶优化配置与日常使用建议

  • 语言设置：在 Settings -> Language 中选择 简体中文。
  • 开机自启：在 Settings 中开启 Startup 开关，确保电脑重启后自动运行。
  • 内核切换：通过点击右下角的内核图标，可以快速查看当前 Mihomo 内核的版本信息。

❓ Clash 无法连接或连上没网怎么解决？常见问题排查

  • 无法访问 Google：请检查”系统代理”是否已开启，并确认节点是否有效。
  • 界面显示异常：尝试点击设置中的 清除缓存 或重启客户端。
  • 代理断开后重置：如遇系统代理未自动重置，可手动点击设置中的重置选项。
