## 🔧 技术SEO修复

### 1. 修复重复标题问题

**检查对象**：
- 分页页面（/page/2/, /page/3/）
- 标签页面（/tags/xxx/）
- 分类页面（/categories/xxx/）
- 归档页面（/archives/）

**解决方案**：
```yaml
# _config.butterfly.yml 或主题配置
# 为分页/标签/分类添加动态标题

# 示例：
# 分页：机场推荐 - 第2页
# 标签：机场推荐 相关文章
# 分类：科学上网知识库 文章列表
```

---

### 2. 添加 canonical 标签

防止重复内容问题：
```html
<link rel="canonical" href="https://clashmac.vip/2026/02/20/airport-recommendations/" />
```

---

### 3. 优化面包屑导航
