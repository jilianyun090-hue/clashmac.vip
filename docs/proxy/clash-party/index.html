⚠️ 建议关闭浏览器自动翻译功能，避免订阅链接被错误处理。

导入订阅

启动 Clash Party 后：

  • 进入配置或订阅管理页面
  • 粘贴你的机场订阅链接
  • 确认导入

导入订阅

选择节点开启代理

订阅导入成功后：

  1. 进入 节点 / Proxies
  2. 选择需要使用的节点（如 🇭🇰 香港 / 🇸🇬 新加坡 / 🇺🇸 美国）
  3. 确认节点生效

选择节点开启代理

模式选择

根据使用场景选择合适的模式：

  • 规则模式（Rule）：推荐日常使用
  • 全局模式（Global）：所有流量走代理
  • 直连模式（Direct）：不使用代理

模式选择

使用建议

  • 📌 日常浏览与软件使用：规则模式
  • 🚀 访问海外服务异常：尝试切换节点
  • 🔄 节点失效或延迟高：更新订阅或更换线路
  • ⚡ 优先选择低延迟、低丢包节点
