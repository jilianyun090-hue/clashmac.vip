## 线路科普：专线、中转与直连有什么本质技术区别？ (FAQ)

了解出海数据的物理通道，能帮您在购买套餐时瞬间识破虚假虚标宣传：

### Q1：IPLC 专线和 IEPL 专线有什么区别？为什么专线机场最稳定？
**A**：
1. **IPLC (International Private Leased Circuit)**：点对点的国际私人专用电路。
2. **IEPL (International Ethernet Private Line)**：以太网国际专线，技术更新，扩容更灵活。
* **共同特点**：两者都是物理层面的跨国私有网络。数据传输从国内入口直接拉到国外落地服务器，**不经过公网，不通过防火长城（GFW）**。因此无论敏感时期公网如何拥堵或封锁，专线依然保持极低延迟、零丢包的绝佳表现。由于租用专线费用极高（通常每 Mbps 宽带月租数十美元），全专线的机场价格定位也相对较高。

### Q2：什么是中转机场（公网中转）与直连机场？
**A**：
* **公网中转**：数据先发送到国内的优化机房（如 BGP 双线机房），再通过加密隧道过墙出境。比直连不易封节点 IP，但晚高峰受公网拥堵影响。
* **直连**：设备直接连接境外的节点 IP。没有任何中间防护和路由优化，节点极易被 GFW 识别并封禁 IP，目前不建议将直连机场作为主力。

## 节点属性：延迟低就一定快吗？节点越多越好吗？ (FAQ)

不要掉入节点参数的盲区中：

### Q3：延迟（Ping值）越低代表速度越快吗？
**A**：**不一定。**
* **延迟 (Ping)**：数据包往返的响应速度。影响网页首次打开、游戏开局体感。
* **带宽 (Speed)**：管道的大小，决定下载速度。
* **示例**：一个香港节点的 Ping 延迟只有 30ms，但如果因为超售导致带宽挤满，看视频照样不停转圈；而美国节点延迟虽有 180ms，但由于带宽充足且零丢包，看 YouTube 4K 视频反而能瞬间加载。选购节点应以丢包率和晚高峰持续带宽为重。

### Q4：机场套餐里的节点数量是越多越好吗？
**A**：**不是。**
大部分人在日常使用中，真正常用的只有香港、日本、新加坡这几个地区。节点再多，如果都是低带宽、高丢包的冷门公网直连节点，只是虚增数量。拥有 30 - 60 个稳定、带有 IEPL 专线且包含解锁说明的节点（如本站主推的飞猫云），体验远好于数百个卡顿节点的劣质机场。

## 地区选择：香港、日本、美国等节点适合什么场景？ (FAQ)

### Q5：如何根据我的上网需求选择节点地区？
**A**：遵循“就近低延迟与风控解锁”原则：
* **香港节点（HK）**：延迟最低（通常 35 - 50ms），国内访问体感最顺滑。适合日常浏览网页、观看港区 Netflix。但注意**香港 IP 无法访问 ChatGPT 和 Gemini**。
* **日本节点（JP）**：延迟约 70 - 90ms，日区原生 IP 丰富。适合日区 App Store 软件购买、玩任天堂日服游戏，也是 ChatGPT 的稳定出口之一。
* **新加坡节点（SG）**：延迟约 70 - 90ms，IP 声誉极高，是 ChatGPT、Claude 等 AI 工具的完美出口。
* **美国节点（US）**：延迟较高（150 - 200ms），适合美区特定流媒体、美服外贸业务及 TikTok 美区运营。

## 解锁风控：什么是原生 IP 与住宅 IP？ (FAQ)

很多国际主流的 AI 和流媒体平台风控极严，对 IP 的类别有着明确划分：

### Q6：什么是原生 IP？和广播 IP 有什么区别？
**A**：
* **原生 IP (Native IP)**：是指服务器 IP 的注册国家与服务器所在的物理机房国家一致。
* **广播 IP (Non-native IP)**：是由机房通过技术手段从别国广播过去的 IP。
**流媒体解锁**：Netflix、Disney+ 等平台极易封禁广播 IP 段，想看版权内容或 4K 画质，必须选择带有“NF 解锁”或“原生 IP”的节点。

### Q7：什么是住宅 IP (家宽 IP)？为什么它风控信誉最高？
**A**：住宅 IP 是由当地基础电信运营商（如 Comcast、PCCW）分配给普通家庭用户的宽带 IP。在 ChatGPT、Claude 和跨境电商风控系统中，住宅 IP 的信任度极高（被判定为真实的本地居民在正常访问）。使用带有住宅 IP 节点的机场，能极大减少访问 AI 工具时频繁出现验证码或拒绝访问的阻碍。

### Q8：为什么我的节点速度极快，却看不了 Netflix 完整版，或者提示 ChatGPT 报错？
**A**：这通常是因为您选择的节点 IP 被该平台列入了“机房代理解析黑名单”。请在客户端中更换名称中带有“NF”、“解锁”、“ChatGPT”或“原生”字样的特定优化节点，以绕过平台的区域风控限制。
