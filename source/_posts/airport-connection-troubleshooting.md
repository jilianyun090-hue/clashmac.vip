## 8种常见原因分析

根据我们收集的1000+用户反馈，机场连不上主要有以下8种原因：

### 原因1：订阅已过期（最常见）⭐⭐⭐⭐⭐

**症状：**
- 节点列表变空
- 提示"订阅无效"
- 客户端显示"0个节点"

**解决方法：**

1. **检查是否过期**
   - 登录机场官网
   - 查看"我的订阅"
   - 看到期时间

2. **续费充值**
   - 点击"续费"或"购买套餐"
   - 完成支付
   - 等待1-5分钟生效

3. **更新订阅**
   - 打开客户端（Clash/Shadowrocket等）
   - 更新订阅链接
   - 等待节点列表刷新

**预防措施：**
- 设置订阅到期提醒
- 使用自动续费
- 准备备用机场

---

### 原因2：节点被墙（高峰期常见）⭐⭐⭐⭐⭐

**症状：**
- 部分节点连不上
- 频繁掉线
- 速度突然变慢

**解决方法：**

**方法1：切换节点**
```
1. 打开客户端
2. 尝试其他地区节点（香港→日本→新加坡）
3. 避免使用"倍率"高的节点
4. 优先选择"IEPL"或"专线"标记的节点
```

**方法2：联系客服**
```
1. 打开机场官网
2. 找到客服入口（工单/Telegram）
3. 报告节点故障
4. 等待技术团队修复（通常1-24小时）
```

**方法3：更新订阅**
```
有些机场会自动添加新节点替换被墙的
更新订阅即可获得新节点
```

---

### 原因3：客户端设置错误⭐⭐⭐⭐

**症状：**
- 节点能连接但无法上网
- 提示"代理连接失败"
- 部分网站能访问，部分不能

**解决方法：**

**Windows（Clash Verge）：**
```
1. 检查"系统代理"是否开启
2. 检查代理模式（推荐"规则"模式）
3. 检查端口冲突（默认7890）
4. 尝试切换"TUN模式"
```

**macOS（ClashX）：**
```
1. 系统偏好设置 → 网络 → 高级 → 代理
2. 确认代理设置正确
3. 尝试"设置为系统代理"
```

**Android（Clash Meta）：**
```
1. 检查VPN权限是否授予
2. 检查"始终开启VPN"设置
3. 尝试重启VPN服务
```

**iOS（Shadowrocket）：**
```
1. 设置 → VPN → 检查VPN配置
2. 删除旧VPN配置，重新添加
3. 检查规则配置是否正确
```

---

### 原因4：本地网络问题⭐⭐⭐⭐

**症状：**
- 所有节点都连不上
- 提示"网络错误"
- 其他网站也访问缓慢

**解决方法：**

**方法1：重启网络**
```
1. 关闭WiFi/拔掉网线
2. 等待10秒
3. 重新连接
4. 测试机场连接
```

**方法2：更换DNS**
```
推荐DNS：
- 阿里DNS：223.5.5.5 / 223.6.6.6
- 腾讯DNS：119.29.29.29
- Google DNS：8.8.8.8 / 8.8.4.4（需翻墙后使用）

Windows设置方法：
控制面板 → 网络和Internet → 网络连接
→ 右键WiFi → 属性 → IPv4 → 使用下面的DNS服务器地址
```

**方法3：检查防火墙**
```
1. 关闭防火墙（临时）
2. 测试机场是否恢复
3. 如果恢复，添加客户端到防火墙白名单
```

**方法4：切换网络**
```
WiFi连不上 → 试试手机热点
电信网络 → 试试联通/移动
```

### 原因5：敏感时期封锁加强⭐⭐⭐

**症状：**
- 之前正常，某个时期突然全部失效
- 机场官网也打不开
- 多个机场同时失效

**常见敏感时期：**
- 重要会议期间（如3月、10月）
- 重大节日（如国庆、春节）
- 国际重大事件期间

**解决方法：**

**方法1：等待机场更新**
```
- 大机场通常12-48小时内恢复
- 关注机场Telegram群公告
- 不要频繁尝试连接（可能加重封锁）
```

**方法2：使用备用机场**
```
这就是为什么推荐准备2个机场：
- 主力机场：日常使用
- 备用机场：应急使用
```

**方法3：切换协议**
```
- SS被封 → 换V2Ray节点
- V2Ray被封 → 换Trojan节点
- 尝试使用"中转"而非"直连"节点
```

### 原因7：机场跑路（最坏情况）⭐⭐

**症状：**
- 官网打不开
- Telegram群被解散
- 客服失联

**判断是否跑路：**
```
✅ 确认跑路：
- 官网域名已过期
- 所有客服渠道失联超过7天
- Telegram群/公告频道消失

⚠️ 可能只是暂时故障：
- 官网临时维护
- 客服响应慢
- 节点全部失效但官网正常
```

**应对方法：**
```
1. 立即停止续费
2. 切换到备用机场
3. 在相关论坛发帖提醒其他用户
4. 记录机场信息，警惕同一运营者的新机场
```

**防跑路建议：**
- ✅ 只买月付或季付
- ✅ 选择运营2年以上的机场
- ✅ 准备2个机场备用
- ✅ 关注机场Telegram群动态

## 分平台详细排查步骤

### Windows排查步骤

1. **检查客户端运行状态**
   ```
   任务管理器 → 详细信息 → 查找"clash.exe"
   如果没有运行 → 重启客户端
   ```

2. **检查端口占用**
   ```
   Win+R → cmd → 输入：
   netstat -ano | findstr "7890"
   
   如果显示被占用 → 修改端口或关闭占用程序
   ```

3. **检查系统代理**
   ```
   设置 → 网络和Internet → 代理
   确认"使用代理服务器"开关状态
   ```

4. **重置网络**
   ```
   Win+X → Windows PowerShell(管理员) → 输入：
   netsh winsock reset
   netsh int ip reset
   ipconfig /flushdns
   
   重启电脑
   ```

---

### macOS排查步骤

1. **检查系统代理设置**
   ```
   系统偏好设置 → 网络 → 高级 → 代理
   确认HTTP代理/HTTPS代理/SOCKS代理设置
   ```

2. **检查客户端权限**
   ```
   系统偏好设置 → 安全性与隐私 → 完全磁盘访问权限
   确认ClashX有权限
   ```

3. **重置网络服务**
   ```
   sudo dscacheutil -flushcache
   sudo killall -HUP mDNSResponder
   ```

---

### Android排查步骤

1. **检查VPN权限**
   ```
   设置 → 应用 → Clash → 权限
   确认"VPN"权限已授予
   ```

2. **清除应用缓存**
   ```
   设置 → 应用 → Clash → 存储 → 清除缓存
   ```

3. **关闭省电模式**
   ```
   设置 → 电池 → 省电模式 → 关闭
   或将Clash加入"白名单"
   ```

4. **检查时间同步**
   ```
   设置 → 系统 → 日期和时间
   确认"自动设置时间"已开启
   ```

---

### iOS排查步骤

1. **重新安装VPN配置**
   ```
   设置 → VPN → 删除Shadowrocket配置
   重新打开Shadowrocket → 允许添加VPN配置
   ```

2. **检查规则配置**
   ```
   Shadowrocket → 配置
   尝试切换到"默认配置"
   ```

3. **重启VPN服务**
   ```
   关闭Shadowrocket
   后台清除
   重新打开并连接
   ```

## 故障排除总结

### 快速检查顺序

1. ✅ **订阅是否过期？** → 续费
2. ✅ **能否打开机场官网？** → 检查网络
3. ✅ **能否更新订阅？** → 检查订阅链接
4. ✅ **节点列表是否为空？** → 更新订阅
5. ✅ **能否连接任一节点？** → 切换节点
6. ✅ **连接后能否上网？** → 检查客户端设置
7. ✅ **其他机场能用吗？** → 判断是机场问题还是本地问题

### 终极解决方案

**如果以上都不行：**

```
1. 完全卸载客户端
2. 重启电脑/手机
3. 重新下载最新版客户端
4. 重新导入订阅
5. 选择不同地区节点测试
6. 仍不行 → 切换备用机场
```

## 常见错误代码含义

| 错误代码 | 含义 | 解决方法 |
|---------|------|---------|
| **timeout** | 连接超时 | 切换节点或检查网络 |
| **403** | 订阅无权限 | 重新获取订阅链接 |
| **404** | 订阅不存在 | 检查订阅链接是否正确 |
| **500** | 服务器错误 | 联系机场客服 |
| **connection refused** | 连接被拒绝 | 节点被墙，切换节点 |
| **DNS failed** | DNS解析失败 | 更换DNS或检查网络 |
