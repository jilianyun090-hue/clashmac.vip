**价格参考：**

### 方案B：自己注册美区ID（免费但麻烦）

**步骤：**

1. **准备材料**
   - 一个从未注册过Apple ID的邮箱

2. **注册流程**
   ```
   1. 打开 https://appleid.apple.com
   2. 点击"创建您的Apple ID"
   3. 填写信息（国家/地区选择"美国"）
   4. 验证邮箱
   5. 完成注册
   ```

3. **配置支付方式**
   - 付款方式选择"无"
   - 填写美国地址（随便填，网上生成的即可）

4. **退出美区账号**

   - 重新登录自己的中国区账号

**⚠️ 注意事项：**
- 不要在"设置"中登录美区账号
- 只在App Store中登录
- 下载完立即退出

## 第四步：导入机场订阅

有3种方法导入订阅，推荐方法1（最简单）。

### 方法1：一键订阅导入（推荐）

**步骤：**

1. **获取订阅链接**
   - 登录机场官网
   - 找到"订阅"或"Shadowrocket订阅"
   - 复制订阅链接（https://开头的一串URL）

2. **在Shadowrocket中导入**
   ```
   1. 打开Shadowrocket
   2. 点击右上角"+"
   3. 选择"类型" → "Subscribe"
   4. 粘贴订阅链接到"URL"
   5. 点击"完成"
   ```

3. **更新订阅**
   - 返回首页
   - 向下拉刷新
   - 等待节点列表加载

**✅ 完成！** 现在你应该能看到一堆节点了。

---

### 方法2：扫描二维码导入

**步骤：**

1. 机场官网找到"Shadowrocket订阅二维码"
2. 打开Shadowrocket，点击左上角扫描图标
3. 扫描二维码
4. 自动导入节点

---

### 方法3：手动添加节点

如果机场没有订阅功能，只提供了单个节点，可以手动添加：

```
1. 打开Shadowrocket
2. 点击右上角"+"
3. 选择"类型"（Shadowsocks/Vmess/Trojan等）
4. 填写服务器信息：
   - 地址（服务器IP或域名）
   - 端口
   - 密码/UUID
   - 加密方式
5. 点击"完成"
```

## 第五步：连接并开始使用

### 基本连接

1. **选择节点**
   - 在首页节点列表中
   - 点击一个节点（建议选香港或日本）
   - 右边会出现黄点（表示已选中）

2. **开启连接**
   - 点击顶部的"未连接"开关
   - 首次使用会提示"添加VPN配置"
   - 点击"允许"，输入手机密码
   - 看到顶部状态栏出现VPN图标 = 连接成功

3. **测试是否成功**
   - 打开Safari浏览器
   - 访问 https://www.google.com
   - 能打开 = 成功翻墙！

---

### 连接模式选择

Shadowrocket有3种连接模式：

| 模式 | 说明 | 适用场景 |
|------|------|---------|
| **配置** | 按照规则分流（推荐） | 日常使用 |
| **全局路由** | 所有流量走代理 | 特殊需求 |
| **直连** | 不使用代理 | 临时关闭 |

**推荐设置：** 保持"配置"模式即可。

## 进阶功能：规则配置

### 什么是规则？

规则决定哪些网站走代理，哪些直连。

**默认规则：**
- 国内网站：直连（不走代理）
- 国外网站：代理
- 广告：拦截

### 导入常用规则

**推荐规则：**

1. **Lhie1规则（最全面）**
   ```
   https://raw.githubusercontent.com/Lhie1/Rules/master/Surge/Surge.conf
   ```

2. **黑白名单规则（简单）**
   ```
   https://raw.githubusercontent.com/h2y/Shadowrocket-ADBlock-Rules/master/sr_top500_banlist_ad.conf
   ```

**导入方法：**
```
1. Shadowrocket首页 → 点击"配置"
2. 点击右上角"+"
3. 粘贴规则链接
4. 点击"下载"
5. 选择刚下载的规则，使用
```

---

### 自定义规则

**场景1：让某个网站走代理**

```
1. 首页 → 点击"配置"
2. 选择当前规则，点击右边的"i"
3. 点击"规则"
4. 右上角"+" → "Domain"
5. 输入域名（如 twitter.com）
6. 策略选择"PROXY"
7. 保存
```

**场景2：屏蔽广告网站**

```
1. 规则类型选"Domain"
2. 输入广告域名
3. 策略选择"REJECT"
```

## 高级功能

### 1. 延迟测试

**功能：** 测试所有节点的延迟，选择最快的

**操作：**
```
1. 首页 → 点击"连通性测试"
2. 等待测试完成
3. 节点右边会显示延迟（ms）
4. 延迟越低越快
```

**建议：**
- <50ms：极快
- 50-100ms：快
- 100-200ms：一般
- >200ms：慢

---

### 2. 流量统计

**查看方法：**
```
1. 首页 → 向下拉
2. 看到"今日使用"、"本月使用"
3. 监控流量消耗
```

---

### 3. 订阅自动更新

**设置方法：**
```
1. 首页 → 点击"设置"
2. 找到"订阅"
3. 开启"打开时更新"
4. 开启"自动后台更新"
```

这样每次打开Shadowrocket，都会自动更新节点列表。

---

### 4. 按需连接

**功能：** 只在需要时连接，省电

**设置：**
```
1. 设置 → 按需连接
2. 开启"打开时连接"
3. 选择"WLAN与蜂窝网络"
```

---

### 5. URL测试（自动选择最快节点）

**设置方法：**
```
1. 首页 → 点击节点右边的"i"
2. 找到"URL测试"部分
3. 开启"自动测试"
4. 设置测试间隔（如600秒）
```

Shadowrocket会自动选择延迟最低的节点。
