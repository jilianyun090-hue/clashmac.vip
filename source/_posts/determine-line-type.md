> 验证翻墙机场真实线路类型（如 IPLC/IEPL 专线、CN2 GIA 优化线路、普通 BGP 中转）的方法是：**通过 Traceroute 路由追踪检测数据包跳数（专线通常仅 3-5 跳，路径不经过公网骨干网络），利用 IP 查询和 ASN（如电信 CN2 的 AS4809、普通 163 的 AS4134）鉴别服务商，并在晚高峰（20:00 - 23:00）测试丢包率与 4K 播放流畅度。**
> 当遇到“节点全红”、连不上或官网打不开时，通常是订阅域名被墙或机场更换入口，应及时在客户端**更新订阅**，或在本地保存的**备用域名和 Telegram 官方公告频道**中获取最新地址，以规避机场跑路失联风险。

## 技术检测：如何利用 Traceroute 与 IP 查询识破虚假线路？

不要盲信商家的宣传文案。我们可以通过以下手段，从技术层面深度分析节点的骨干网路由：

### 1. Traceroute 路由追踪（最关键的验证手段）
使用系统自带的命令行工具（Windows 用 `tracert`，Mac/Linux 用 `traceroute`），对节点对应的服务器 IP 或域名进行追踪，分析数据包过墙前的路由路径：
* **真正的 IPLC / IEPL 专线**：路由跳数极少（通常在 5 跳以内），国内段和境外段点对点传输，**完全不经过公网的过墙路由器**，不会在路由路径中看到海关公网节点。
* **CN2 GIA (电信特优线路)**：会在国内出口路由的 IP 地址中，清晰看到以 `59.43.x.x` 开头的 IP 节点（属于电信 CN2 骨干网，ASN 为 AS4809）。
* **普通公网中转 / 163 直连**：会经过漫长且拥堵的国内公网路由，出现以 `202.97.x.x` 开头的 IP 地址（属于中国电信 163 骨干网，ASN 为 AS4134）。

```bash
# Windows 检测示例
tracert target-node.com
```

### 2. 检查节点入口与出口 IP 归属地及 ASN 号
您可以使用 [IP.SB](https://ip.sb/) 等工具查询节点归属地：
* **IEPL专线/BGP中转**：入口 IP 通常在深圳、上海等沿海地区，出口 IP 在香港或日本。虽然两地相隔很远，但在专线支撑下，从上海入口到香港出口的内网延迟可低至 20ms - 30ms。

## 测速与体感：如何评估晚高峰的真实性能？ (FAQ)

### Q1：机场节点丢包是什么意思？对网络体验有什么影响？
**A**：丢包率（Packet Loss）指在网络传输中丢失的数据包比例。
1. **轻度影响（丢包率 < 1%）**：浏览网页、文字聊天基本无感。
2. **重度影响（丢包率 > 5%）**：看视频频繁缓冲，Zoom 视频会议花屏，玩游戏瞬移、卡墙。
**线路鉴别**：真正的专线即便在晚高峰，丢包率也必须维持在 0.5% 以下；若晚高峰丢包率飙升到 10% 以上，说明这是普通公网中转或假专线。

### Q2：机场测速应该怎么看才准确？测速软件可信吗？
**A**：测速必须要在**晚高峰（20:00 - 23:00）**进行。白天测速大家都很快，没有决策参考价值。建议在 Speedtest 里手动选择距离较远的海外服务器测试单线程下载速率。需要注意的是，部分劣质机场会针对测速服务器域名进行特殊路由伪装优化（俗称“黄金测速节点”），所以在实际体验中，建议以播放 YouTube 4K 视频看详细码率（Stats for nerds）为最真实的标准。

### Q3：为什么测速结果很快，实际看视频或用 ChatGPT 却很卡？
**A**：这通常有两个原因：
1. **持续带宽受限**：测速是短时间内的并发高流量，而看 4K 视频需要持续的宽带吞吐量。
2. **IP 干净程度（解锁风控）**：有些节点测速跑满了 200M，但因为 IP 属于被 ChatGPT 或 Netflix 拉黑的数据中心 IP 段，会导致页面直接返回风控拒绝或降级播放（只能看 Netflix 自制剧），这也无法从单纯的速度测试里反映出来。

## 故障排查：连不上或节点全红怎么解决？ (FAQ)

### Q4：为什么刚买的机场节点全是超时（Timeout）或全部全红？
**A**：请按照以下步骤自查：
1. **检查本地网络**：断开代理，确认正常网络能否正常上网。
2. **检查套餐状态**：登录机场官网，确认套餐是否已到期、或流量是否已耗尽。
3. **更新订阅链接**：在 Clash Verge 或 Shadowrocket 中右键/下拉，选择“更新订阅”以同步最新的服务器 IP。
4. **校准系统时间**：很多新型代理协议（如 VMess/Trojan）对设备本地时间要求极其严苛，如果您的电脑/手机系统时间与北京时间相差超过 90 秒，会导致所有节点连接失败。

### Q5：Clash 导入订阅失败、提示“Invalid URL”怎么处理？
**A**：这通常是因为：
1. 复制的链接不完整或多复制了空格。
2. 订阅链接域名已被防火墙屏蔽，导致本地客户端无法直接访问机场服务器拉取节点列表。
**解决办法**：开启一个可用的免费节点或临时节点，开启系统代理，然后再点击 Clash 的订阅更新；或尝试利用机场后台提供的“Clash 订阅转换”生成新的备用链接进行导入。

## 防跑路预案：如何应对机场官网失联或域名被封？ (FAQ)

### Q6：机场“跑路”是什么意思？有哪些常见的跑路前兆？
**A**：跑路是指机场主关停服务器、关闭官网、解散社群卷款消失的行为。
**三大跑路高危信号**：
1. **骨折促销**：突然推出大幅偏离成本逻辑的活动（如“终身 5 折”、“年付买一送一”），试图在关站前再割最后一波。
2. **长期故障**：服务器大面积挂掉，客服工单多天不予答复，且没有修复迹象。
3. **沟通静默**：机场 Telegram 官方交流群突然禁言、或者频道长时间未有维护更新。

### Q7：机场官网突然打不开了，是不是跑路了？该怎么办？
**A**：**90% 的情况只是官方域名被 GFW 屏蔽，并非跑路。**
1. **第一步**：断开您的代理，使用本地网络访问。或者反过来，开启备用梯子访问。
2. **第二步**：寻找该机场提供的**备用官网地址**或**发布页**。
3. **第三步**：如果官网和备用域名都无法访问，请立即打开 Telegram 软件，进入**机场官方公告频道**获取最新的官网域名。通常正规机场在域名被封后，都会在 1-2 小时内发布免墙新域名。
